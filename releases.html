Release notes

What's new in Cue

Every version, newest first. Cue checks for updates once a day, or choose Check for Updates… in the Cue menu.

0.4.1

Latest17 October 2026 GitHub release
  • Cards survive a resize. Switching between the tab sidebar and tabs on top, splitting a pane, resizing the window or changing the font no longer turns earlier command cards back into plain text; each card follows its lines when the terminal rewraps.
  • No more doubled commands. A command sent while the shell was still drawing its prompt (common with slow prompts like Powerlevel10k, gitstatus or nvm) could show up twice, and keys typed right after Return could end up glued to the next command. Cue now waits for the line editor before sending, and holds keys typed right after Return until it knows whether they belong to the composer or the running program.

0.4.0

16 October 2026 GitHub release
  • Command palette (⌘K). Search every menu command, slash command, open tab, theme (previewed live as you arrow through), snippet and recent folder from one floating list, with your most used actions first; type > to search history. Clear moves to ⇧⌘K.
  • Quick Terminal (⌃`). A terminal slides down from the top of the screen over any app and keeps its session between visits. Press the shortcut again or Esc on an empty prompt to put it away; drag its bottom edge to resize. Shortcut, screen, height and hide-on-focus-loss are in Settings → Quick Terminal.
  • Motion pass. Command cards fade in as they start; a finished run's pill pops from the spinner to a drawn check or cross, and a failed card's stripe flares once. The Command/Ask switch slides, notices and hover actions ease in, the welcome screen staggers in on a new pane, new tabs and split panes grow in, the sidebar's labels fade before it folds, a long command finishing in another tab bounces its dot (now green until you look), Stop flashes, and theme changes crossfade the window. Reduce Motion keeps the fades and drops the movement. A hidden running strip no longer animates its loader, so an idle pane drops from about 40% CPU to under 1%.
  • Projects. Cue now knows when a pane is inside a project: Node (with its package manager from the lockfile), Swift (Package.swift, Xcode schemes, XcodeGen), Rust, Go, Python (and its venv), Make, just and Docker Compose. A project chip in the composer opens a Project panel of runnable tasks (Return inserts, ⌘Return runs) with git state and quick pull, push, branch switch and stash, which only insert their command. The welcome screen shows the top four tasks, /run <task> completes and runs a task, /git opens the branch switcher, the ⌘K palette lists “Run task: …” items, and a quiet chip warns when the active node or python differs from .nvmrc, .node-version, .python-version or .tool-versions. Detection runs off the main thread, is cached, refreshes when the key files change, and never reads node_modules.
  • Share as Image… Any command card can become a PNG: its command, status, folder and colored output in the window chrome of the current or a chosen theme, on a gradient, the theme or a transparent background. Secrets are redacted by default. Copy, save or share it from the preview.
  • Pick up where you left off. Cue reopens every window with its tabs, names, splits and folders, and (Settings → General) shows each pane's last 1,000 lines dimmed above a "Restored from" divider. Secrets are masked and hidden answers never saved.
  • Fold long output. Click a card's chevron or ⌥-click its header to collapse it to one line; cards over 200 lines open trimmed to their first and last 20. ⌘⌥← collapses every card, ⌘⌥→ expands them. Pane selection moved to ⌃⌘ + arrows.
  • Find in output. ⌘F searches the whole pane, a selected card or failed cards only, with match case and regex; ⌘G and ⇧⌘G step through, and matches inside folded cards open them.

0.3.1

16 October 2026 GitHub release

The first public release of Cue, a terminal that doesn't feel like one.

  • A composer instead of a prompt. Type commands in a native input bar with autocomplete, history and / commands (/ask, /explain, /history, /snippets, /cd, /theme, /clear).
  • Every command is a card. Its output, exit code and duration stay together; copy the command or the output, re-run it, or explain a failure.
  • Programs that ask, get a field. When a running program asks for input (a password, a yes/no), the composer becomes a question field; Esc hands the keys back to the terminal.
  • AI with your own Claude. Explain, fix or ask about any command with your Anthropic key or the claude CLI you already have. Secrets are redacted before anything is sent.
  • Themes, sidebar tabs and splits. A tab sidebar (⌘B folds it) or a strip along the top, split panes, and a theme library.
  • History and snippets. ⌃R searches every command you ran, with saved snippets beside it.
  • Updates itself. Check for Updates… in the Cue menu; Cue also checks once a day.
