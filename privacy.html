Privacy

Cue collects nothing.

Last updated 16 October 2026

Cue has no analytics, no telemetry, no crash reporting service and no account. It never builds a profile of you. What you type, what your commands print and what is in your files stay on your Mac. Cue only uses the network in the two cases below.

1. Checking for updates

Cue uses Sparkle to look for new versions. Once a day, and when you choose Check for Updates…, it requests https://coursion-studio.github.io/cue/appcast.xml. That is a standard Sparkle request: it carries the app's version and your macOS version, and like any web request it reveals your IP address to the host. Cue does not send Sparkle's optional system profile, and the request carries nothing about you or what you do in Cue.

The feed is a static file on GitHub Pages and new versions download from GitHub Releases. We don't run a server that sees these requests.

2. AI features you use

Explain, fix and ask only send anything when you use them, and only after you have set them up:

  • With your own Anthropic API key. The request goes straight from your Mac to api.anthropic.com. It holds what the feature needs: your question, or the command, its exit code and the last lines of its output, plus your macOS version, your shell's name and the current folder so the answer fits your setup. Before it leaves your Mac, the question, command and output go through a redactor that masks tokens, passwords and keys. Anthropic's own privacy policy covers what happens there.
  • With the claude CLI. Cue runs the claude program already installed on your Mac and passes it the same redacted text. That tool then talks to Anthropic under your own sign-in and its own terms.

Your API key is stored in the macOS Keychain. It is never written to a file, logged or sent anywhere but Anthropic. If you never set up a key or the CLI, nothing is sent. You can also switch AI off in Settings.

What stays on your Mac

  • Shell history and snippets. The commands you run and the snippets you save are kept in Cue's folder in Application Support. They never leave your Mac.
  • Settings and themes. Kept in your user preferences and in the same Application Support folder.
  • Your shell. Cue starts your own shell with a few prompt marks added. It doesn't edit your dotfiles.

This website

This site has no analytics, no cookies, no tracking pixels and no third-party scripts. It is served by GitHub Pages, and GitHub may log requests (such as your IP address) as part of running that service, under GitHub's own privacy statement. Download links point to GitHub Releases.

Changes and contact

If Cue ever starts sending something new, this page changes first and the release notes say so. Cue is made by Coursion Studio; you can reach us through coursion.studio.
